What we would fix first

Make the new name the only name

The homepage banner already announces the rebrand to A Lasting Fitness, but the page title, the header, and the web address itself still all say TFW Connecticut. A new visitor lands not knowing which name is current, which gym they're looking at, or whether the site is even up to date.

  • One consistent name across title, header and URL.
  • Works properly on a phone, which is where people decide.
  • One clear way to reach you, and one to book.
